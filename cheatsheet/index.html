01 · Inventory Fundamentals
Core Concept

Inventory Management 101

Tradeoff between holding cost vs. ordering cost vs. shortage cost.

Key Decisions

  • When to order — re-order point, review frequency
  • How much to order — sales forecast, lead time, on-hand + in-transit stock
  • Where to store — locating SKUs, shelf-space allocation

4 Cost Components

C
Unit product cost — constant; relevant only with discounts
Co
Ordering cost (Rs/order) — transport, inspection, rework
Cc
Carrying cost (Rs/unit/yr) — capital, space, obsolescence
Cs
Shortage cost (Rs/unit/yr) — goodwill loss, lost profit
Supply Chain

Supply Chain Structure

Import Flow (First–Middle–Last Mile)

Vendor cargo loading
Overseas Port first mile
Inbound Port govt. clearance, unloading
Distribution Centres space forecast, splitting shipments
Local Warehouses searching, handling, fulfilment
Stores → Customers shelf display, impulse buying

Multi vs. Omni-Channel

  • Multi-channel: separate inventory pools per channel
  • Omni-channel: unified inventory, seamless experience across website, stores, marketplaces
  • Key challenge: returns management + allocation across channels
02 · Deterministic Inventory Models
Classic Model

Economic Order Quantity (EOQ)

Assumes deterministic, constant annual demand D. Instantaneous delivery. No shortage. Continuous review.

Key Relationships

Orders/year = D / Q
Annual Order Cost = D·Co / Q
Avg Inventory = Q / 2
Annual Carry Cost = Q·Cc / 2
TC(Q) = D·Co/Q + Q·Cc/2

Optimal Solution (dTC/dQ = 0)

Q* = √(2·D·Co / Cc)

TC* = √(2·D·Co·Cc)
TC curve is flat near optimum — 15% deviation in Q causes only ~2% cost increase.

Numerical Example

D=10,000, Co=₹300
Cc=₹4/unit/yr
Q*
= √(2×10000×300/4) = 1224.75 units
TC*
= √(2×10000×300×4) = ₹4898.98/yr
Orders/yr
= 8.17
03 · Probabilistic Single-Period — News Vendor Problem
Stochastic · Single Period

News Vendor Model

One-shot ordering decision before demand is revealed. Leftover items salvaged; shortages result in lost sales. E.g. Diwali lights, newspapers.

Notation

X
Random demand (rv)
G(x)
CDF of demand: Pr(X ≤ x)
g(x)
PDF of demand
c0
Per-unit overage cost (leftover → salvage loss)
cs
Per-unit underage/shortage cost (lost profit)
Q
Order quantity (decision variable)

Assumptions

  • Products separable; single planning period
  • Demand is random; deliveries arrive before demand
  • Overage and shortage costs are linear
Optimisation

News Vendor — Solution

Total Cost Function

Y(Q) = c0·∫0Q(Q−x)g(x)dx + cs·∫Q∞(x−Q)g(x)dx

Optimal Q — Critical Ratio

G(Q*) = Pr(X ≤ Q*) = cs / (cs + c0)

Normal Demand

Q* = μ + z·σ, where Φ(z) = critical ratio

Worked Example

  • Cost=Re1, sells=₹2, salvage=50p → cs=1, c0=0.5
  • Ratio = 1/(1+0.5) = 0.67 → z = 0.44
  • μ=10,000, σ=1,000 → Q* = 10,440 units
Ratio > 0.5: higher variability increases order. Ratio < 0.5: higher variability decreases order.
04 · Dynamic Inventory Management (Deterministic DP)
Multi-Period · Deterministic

Dynamic Programming Setup

Extends EOQ to multi-period horizon T with known but time-varying demand Dt.

Assumptions

  • Demand Dt is dynamic but known (deterministic)
  • Instantaneous delivery (no lead time)
  • Fixed ordering + variable product + holding cost
  • Limited storage & ordering capacity
  • Demand must be met each period

DP Formulation

t
Stage (day/week), t = 1…N
st
State = inventory at start of period t
at
Action = order quantity at period t
ft(st)
Total optimal cost from period t onward
st+1 = Max(st + at − Dt, 0) [lost sales]
st+1 = st + at − Dt [backorders]

Bellman Equation

ft(st) = mina [ C(st,at) + ft+1(st+1) ]
Worked Example

Backward Induction (T=4 weeks)

Parameters

D
3, 4, 2, 4 units (weeks 1–4)
Co
$4 fixed ordering cost
C
$2/unit product cost
Cc
$0.5/unit/period holding
Max order
5 units; Warehouse cap: 4 units

Solve Backward: t = 4 (D4=4)

s4a4f4(s4)
044 + 2×4 = $12
134 + 2×3 = $10
224 + 2×2 = $8
314 + 2×1 = $6
400 + 2×0 = $0

Then compute f3(s3) using Bellman, propagate backward for t=2 and t=1.

Holding Cost at end of period t

Cc × Max(st + at − Dt, 0)
05 · Stochastic Inventory — MDP & Reinforcement Learning
Stochastic · MDP

Stochastic Inventory as MDP

Demand unknown — only a probability distribution is known. Framework: Markov Decision Process.

MDP Components

Stage
t = 1, 2, …N (days)
State st
Inventory level ∈ {0,1,…,M}
Action at
Order qty ∈ {0,1,…,M−st}
rt(s,a)
Reward = expected revenue − ordering − holding cost

Reward Function

rt(s,a) = E[Min(Dt, s+a)·price] − C0(a) − Cc(s+a)
C0(a) = K + c(a) if a>0, else 0

Transition Probabilities Pr(s'|s,a)

ConditionProbability
s' ∈ (s+a, M]0 (demand can't be negative)
s' ∈ (0, s+a]ps+a−s'
s' = 0∑k>s+a pk

Example Parameters

K=$4, c(u)=$2u
h(u)=$u, f(u)=$8u
M=4, N=3, λ=0.95
p(1)=¼, p(2)=½, p(3)=¼
Policy

Policies & (s, S) Policy

A Markov decision rule maps each inventory level st → order quantity at.

Famous (s, S) Policy

If inventory < s → order up to S
If inventory ≥ s → place no order

Optimal for stochastic problems under fixed ordering cost K.

Stochastic Bellman Equation

u*t(s,a) = r(s,a) + Σj∈S λ·p(j|s,a)·u*t+1(j)

Value Iteration

vn(s) = maxa { r(s,a) + Σj λ·p(j|s,a)·vn+1(j) }
  1. Pick initial v⁰, threshold ε', set n=0
  2. ∀s: compute vn+1(s) = maxa{r(s,a) + Σ λ·p·vn(j)}
  3. If ‖vn+1−vn‖ ≤ ε' → output policy. Else repeat.
Convergence guaranteed when λ < 1.
Algorithm

Policy Iteration

  1. Init: pick arbitrary decision rule d0
  2. Policy Evaluation: solve vn(s) = r(s,dn) + Σλ·p·vn(j) for all s
  3. Policy Improvement: dn+1 = argmaxa{r(s,a) + Σλ·p·vn(j)}
  4. If dn+1 = dn: STOP (optimal). Else repeat.
Value Iteration
  • Updates value function
  • Simple per-iteration
  • Many iterations needed
Policy Iteration
  • Updates policy directly
  • Solves linear system
  • Fewer iterations
Reinforcement Learning

Q-Learning (Model-Free RL)

Model-Based MDP

Pr(s'|s,a) is known. Use Value/Policy Iteration.

Model-Free

Transition probabilities unknown. Learn from experience.

Q-Function Update Rule

Qt+1(s,a) = Qt(s,a) +
αt · [ r(s,a) + λ·maxa'Qt(s',a') − Qt(s,a) ]
αt
Learning rate (decreasing over time)
λ
Discount factor
Q(s,a)
Quality of action a in state s
Converges to Q* under appropriate conditions. Optimal policy: π*(s) = argmaxa Q*(s,a)
06 · Time Series Forecasting
Demand Forecasting

Forecasting Overview

Two tasks: (1) identify patterns in historical data; (2) discover relationships among variables.

Data Decomposition Components

  • Trend — long-term direction (up/down)
  • Seasonal — regular periodic fluctuations
  • Cyclic — irregular multi-year waves
  • Random — noise / unexplained variation

Methods

Moving Avg Exp. Smoothing Double ES Holt's Winter's AR(p) ARMA ARIMA
Method

Exponential Smoothing (ES)

Weighted average of current observation & previous forecast. Parameter α ∈ (0,1).

Ft+1 = α·Dt + (1−α)·Ft
  • Smaller α → smoother, slower response
  • Larger α → more weight on recent data
  • Initial F1: use first value, last, or simple average

ES lag when trend exists

Lag = Dt − Ft = ((1−α)/α) · b

Solution: Double Exponential Smoothing (apply ES twice)

Method

Double ES & Holt's Method

Double ES

b = (S − S') · α/(1−α), a = 2S − S'
Ft+m = a + b·m (m steps ahead)

Holt's Method (level + slope)

Ft+1 = at + bt
at = α·Dt + (1−α)·(at-1+bt-1)
bt = β·(at−at-1) + (1−β)·bt-1
at
Level estimate (smoothed)
bt
Slope/trend estimate
α, β
Smoothing parameters

Worked Example

α=0.2, t=8
S=105.4, S'=104.8
b
= (105.4−104.8)×0.2/0.8 = 0.15
a
= 2×105.4−104.8 = 106.0
F9
= 106.0 + 0.15 = 106.15
Method

Winter's Model & AR Models

Winter's Model (trend + seasonality)

Ft+1 = (at+bt) · Ct+1
at+1 = α·Dt+1/Ct+1 + (1−α)·(at+bt)
bt+1 = β·(at+1−at) + (1−β)·bt
Ct+p+1 = γ·Dt+1/at+1 + (1−γ)·Ct+1
at, bt, Ct
Level, trend, seasonality index
p
Length of seasonal cycle
α, β, γ
Smoothing params

AR(p) / ARMA

AR(1): D̂t = φ1·D̂t-1 + εt
MA(1): Ft = μ − θ·εt-1
ARMA: D̂t = φ1·D̂t-1 − θ·εt-1 + εt

Box-Jenkins (1976) — best for short-term forecasting. Estimate φ, θ via OLS/MLE.

07 · IoT / IIoT — Sensorization
Technology

IoT Fundamentals

Internet of Things: network of interconnected devices exchanging data with minimal human intervention.

3 Forms of IoT

Consumer
Smart homes, personal connectivity, entertainment
Commercial
Banking, insurance, financial services, e-commerce
Industrial
Manufacturing, utilities — focus of this course

How IoT Works

  1. Device collects analog data (light, sound, temp, motion…)
  2. Analog → digital conversion by sensors
  3. Data sent to cloud wirelessly
  4. Software processes & decides: alert or auto-adjust

7 Principles of IoT

  1. Big Analog Data — convert analog to digital everywhere
  2. Constant Connection — 24×7 monitoring, maintenance, motivation
  3. Real Time — truly real-time data
  4. Spectrum of Insights — real-time + archival
  5. Immediacy vs. Depth — tradeoff bridged by compute
  6. Shift Left — edge computing near IoT devices
  7. Next "V" — adds Visibility to Volume/Velocity/Variety/Veracity/Value
Applications

IIoT in Manufacturing — Key Application Areas

Inventory
  • RFID tags give every item a UID
  • Readers scan & transmit to cloud
  • Real-time location + supply chain tracking
  • Tracks material movement speed
Predictive Maintenance
  • Traditional: time-based (inefficient)
  • Only 18% of failures are age-related; 82% random
  • Sensors monitor operating environment
  • Cloud analytics evaluate actual wear
Quality Control
  • Traditional: sequential (produce → test)
  • IIoT: parallel thermal & video monitoring
  • Test at every manufacturing step
  • Catch defects early → reduce rework
Smart Metering
  • Monitors water, electricity, fuel
  • Granular usage → effective deployment
Industrial Safety
  • Track absences, mishaps, machinery damage
  • Wearables monitor health metrics
  • Real-time safety alerts
Data Flow
  • Collect data from assets & processes
  • Send to cloud for processing
  • Automated decision-making & response
  • Edge computing for real-time critical actions
