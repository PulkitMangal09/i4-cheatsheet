01 📦 Inventory Problem — Basics

An inventory problem is a decision theoretic problem about when and how much to stock. The decision maker observes current inventory level and decides whether to order more. The core tradeoff is between carrying cost (high stock = high holding cost) and ordering cost (low stock = frequent orders).

Deterministic Models

Demand and costs are known with certainty. Solved once. Example: EOQ, Dynamic lot-sizing via DP.

Stochastic / Probabilistic Models

Demand follows a probability distribution. Require expected value optimization. Examples: Newsvendor, MDP.

About 80% of items in manufacturing are bought from outside vendors. Key decisions: How much to order (Q)? and When to order?

02 💰 Cost Components

CostSymbolUnitWhat it includes
Product costCRs/unitUnit price. Does NOT affect Q* unless quantity discount exists.
Ordering costC₀ / KRs/orderPeople, stationery, communication, follow-up, transportation, inspection, rework, rejects. Fixed per order regardless of quantity.
Carrying / Holding costCc / ChRs/unit/yearCapital (often Cc = iC), space, power, pilferage, obsolescence, special facilities. Charged on average inventory.
Shortage costCsRs/unit/yearLost customer goodwill, cost of losing a customer, lost profit from not delivering. Hard to measure — usually set high to minimize shortages.
⚠ Exam Traps Product cost C does NOT affect EOQ (unless discount). · Shortage cost ≠ return cost. · Obsolescence → carrying cost. · Inspection of incoming goods → ordering cost.

03 📐 EOQ — Economic Order Quantity

Assumptions

Constant annual demand D, instantaneous delivery, no shortages, infinite planning horizon, single item.

Formulas

\[ Q^* = \sqrt{\frac{2DC_o}{C_c}} \] \[ TC^* = \sqrt{2DC_oC_c} \] \[ N = \frac{D}{Q^*} \quad \text{(orders/year)} \] \[ \text{Avg Inventory} = \frac{Q^*}{2} \qquad \text{Annual Carrying Cost} = \frac{Q^*C_c}{2} \qquad \text{Annual Order Cost} = \frac{DC_o}{Q} \]
D = annual demand · C₀ = ordering cost/order · Cc = carrying cost/unit/year
💡 Golden Rules At Q*: Annual ordering cost = Annual carrying cost (always equal). · TC curve is very flat near Q* — a 15% deviation from Q* causes only ~2% cost increase. This gives flexibility to round Q to practical quantities.

EOQ Graph — Labels (exam favourite)

Memorise this mapping Y-axis = Cost · X-axis = Quantity · U-shaped curve = Total Cost · Rising line = Carrying Cost · Falling curve = Order Cost · Minimum point on X = EOQ (Q*)

EOQ Error Calculation

\[ \text{Error (\%)} = \frac{Q_{estimated} - Q_{actual}}{Q_{actual}} \times 100 \]
Compute Q_est and Q_act separately using Q* formula, then substitute.

Numerical Example (from lecture)

D = 10,000/yr · C₀ = Rs 300/order · Cc = Rs 4/unit/yr

\[ Q^* = \sqrt{\frac{2 \times 10000 \times 300}{4}} = \sqrt{1{,}500{,}000} = 1224.75 \] \[ TC^* = \sqrt{2 \times 10000 \times 300 \times 4} = \mathbf{Rs\ 4898.98} \quad N = \frac{10000}{1224.75} = 8.17 \text{ orders/yr} \]

04 🔄 Dynamic Inventory Management (Deterministic DP)

Extends EOQ to a multi-period horizon with time-varying demand D₁, D₂, … Dₜ. Uses Dynamic Programming with backward recursion (Bellman equation).

Assumptions

Demand per period is known but varies. Instantaneous delivery. Fixed ordering cost + variable product cost + holding cost at end of each period. Limited warehouse and ordering capacity.

DP Formulation

ComponentDefinition
StageEach time period t = 1, 2, … N
State variable sₜInventory level (beginning inventory) at period t
Action set aₜOrder quantity at time t
f_t(sₜ)Total cost of meeting demand from period t onwards, when state is sₜ
C(sₜ, aₜ)Immediate cost of ordering aₜ units when state is sₜ

Key Equations

\[ s_{t+1} = \max(s_t + a_t - D_t,\ 0) \quad \text{(lost sales)} \] \[ s_{t+1} = s_t + a_t - D_t \quad \text{(backordering)} \] \[ f_t(s_t) = \min_{a_t} \left[ C(s_t, a_t) + f_{t+1}(s_{t+1}) \right] \quad \text{(Bellman equation)} \] \[ \text{Holding cost at end of period t: } C_c \times \max(s_t + a_t - D_t,\ 0) \]
Solve backward: start from period T (last), work back to period 1.

4-Week Worked Example (from lecture)

D = {3, 4, 2, 4} · C₀ = $4 · C = $2/unit · Cc = $0.5/unit/period · Max order = 5 · Warehouse cap = 4 units

t=4, D₄=4 — Terminal period (trivial: just order what's needed) s₄=0 → order 4, cost = 4+2×4 = $12 · s₄=1 → order 3, cost = $10 · s₄=2 → order 2, cost = $8 · s₄=3 → order 1, cost = $6 · s₄=4 → order 0, cost = $0
t=3, D₃=2 — Use Bellman: f₃(s₃) = min[C(s₃,a₃) + f₄(s₄)] Holding cost = 0.5 × Max(s₃+a₃−2, 0). For each s₃, enumerate feasible a₃ and pick the minimum total cost.

05 🎯 Newsvendor Model (Single-Period, Probabilistic)

Used when demand is random and you order once before demand occurs (perishable/seasonal goods). Named after a newspaper vendor facing the same problem.

Assumptions (all 5 must be known)

AssumptionValid?
Products are separable✅
Planning for single period✅
Demand is random (stochastic)✅
Deliveries made before demand occurs✅
Shortage and excess costs are linear✅
Demand is deterministic❌ FALSE — this breaks the model

Notations

SymbolMeaning
XRandom demand
G(x)CDF of demand
g(x)PDF of demand
c₀Per unit cost of leftover (overstock) = c − s (cost minus salvage)
cₛPer unit cost of shortage (understock) = p − c (price minus cost)
QDecision variable (order quantity)

Optimal Condition (Critical Ratio)

\[ G(Q^*) = \Pr(X \leq Q^*) = \frac{c_s}{c_s + c_0} = CR \]
For Uniform distribution U[a, b]: \[ Q^* = a + CR \times (b - a) \] For Normal distribution: \[ Q^* = \mu + z\sigma \quad \text{where } \Phi(z) = CR \]
c₀ = overstock cost · cₛ = understock cost · CR = Critical Ratio

Left / Right Rule

ConditionCRQ* position
c₀ < cₛ (overstock cheaper)> 0.5RIGHT of mean ✅
c₀ > cₛ< 0.5LEFT of mean
Managerial Insight from lecture If demand is normally distributed and variability increases: Q* increases if CR > 0.5; Q* decreases if CR < 0.5.

Numerical Example (Diwali Lights — Normal demand)

Cost = Re 1 · Selling price = Rs 2 · Salvage = Rs 0.50 · Demand ~ N(10,000, 1,000)

\[ c_s = 2-1 = 1, \quad c_0 = 1-0.5 = 0.5 \] \[ CR = \frac{1}{1.5} = 0.67 \Rightarrow z = 0.44 \text{ (from standard normal table)} \] \[ Q^* = 10000 + 0.44 \times 1000 = \mathbf{10{,}440 \text{ units}} \]

06 🎲 Stochastic Inventory as MDP (Markov Decision Process)

When demand is probabilistic across multiple periods, the deterministic DP becomes an MDP. Objective shifts from cost minimization to reward maximization.

MDP Assumptions

Discrete demand Dₜ = 1,2,… · Instantaneous delivery (no lead time) · IID demand with stationary PMF p_j = Pr(Dₜ = j) · Warehouse capacity M units · Non-perishable inventory · Lost sales (unmet demand is lost, not backordered)

MDP Formulation

ComponentDefinition
StageDays t = 1, 2, … N
State sₜInventory level at beginning of day t (0 to M)
Action aₜOrder quantity at time t
Reward r(sₜ, aₜ)E[Min(Dₜ, sₜ+aₜ) × price] − C₀(aₜ) − Cc(sₜ+aₜ)·Dₜ

State Transition

\[ s_{t+1} = \max(s_t + a_t - D_t,\ 0) \quad \text{(lost sales)} \] \[ s_{t+1} = s_t + a_t - D_t \quad \text{(backordering)} \]

Ordering Cost Structure

\[ C_0(a_t) = \begin{cases} K + c(a_t) & \text{if } a_t > 0 \\ 0 & \text{if } a_t = 0 \end{cases} \]
K = fixed ordering cost · c(aₜ) = variable cost = unit price × quantity

Revenue Function

\[ F_t(u) = \sum_{j=0}^{u-1} f(j) \cdot p_j + f(u) \cdot q_u \quad \text{where } u = s_t + a_t \]
f(j) = price × j · q_u = Pr(D ≥ u) = probability demand exceeds available stock

State Transition Probabilities

\[ \Pr(s'|s,a) = \begin{cases} 0 & \text{if } s' \in (s+a, M] \\ p_{s+a-s'} & \text{if } s' \in (0, s+a] \text{ and } s+a \leq M \\ \sum_{k>s+a} p_k & \text{if } s' = 0 \text{ and } s+a \leq M \end{cases} \]

The (s, S) Policy

Famous Policy If beginning inventory < s → order up to S (order S − current inventory). · If beginning inventory ≥ s → do NOT order. · This is called the (s, S) policy or reorder point policy.

07 🔁 Value Iteration & Policy Iteration

Bellman Equation (finite horizon)

\[ u_t^*(s, a) = r(s, a) + \sum_{j \in S} \lambda \cdot p(j|s,a) \cdot u_{t+1}^*(j) \]
λ = discount factor (0 < λ ≤ 1) · p(j|s,a) = transition probability · Solve backward from terminal period.

Infinite Horizon Bellman

\[ v(i) = \max_{a \in A_s} \left\{ r(i,a) + \sum_{j \in S} \lambda \cdot p(j|s,a) \cdot v(j) \right\} \]

Value Iteration Algorithm (4 steps)

  1. Select initial value function v⁰ ∈ V, set convergence threshold ε', set n = 0.
  2. For all s ∈ S, calculate: \( v^{n+1}(s) = \max_{a \in A_s} \left\{ r(s,a) + \sum_{j \in S} \lambda \cdot p(j|s,a) \cdot v^n(j) \right\} \)
  3. If ‖v^{n+1} − v^n‖ ≤ ε' → go to Step 4. Else increment n and return to Step 2.
  4. Extract policy: \( d_\epsilon(s) = \arg\max_{a \in A_s} \left\{ r(s,a) + \sum_j \lambda \cdot p(j|s,a) \cdot v^{n+1}(j) \right\} \)

Policy Iteration Algorithm (4 steps)

  1. Set n = 0, select arbitrary decision rule d₀ ∈ D.
  2. Policy Evaluation: Solve for v^n(s) = r(s, d₀) + λ Σ p(j|s,a) v^n(j) (linear system)
  3. Policy Improvement: d_{n+1} = argmax { r(s,a) + λ Σ p(j|s,a) v^n(j) }
  4. If d_{n+1} = d_n → STOP. Else increment n, go to Step 2.
Value Iteration vs Policy Iteration Value Iteration: updates values, extracts policy at end. Converges asymptotically. · Policy Iteration: alternates evaluation + improvement. Converges faster but each step is more expensive.

08 🤖 Q-Learning (Reinforcement Learning)

Model-based MDP

Transition probabilities Pr(s'|s,a) are known. Can solve exactly with value/policy iteration.

Model-free (Q-Learning)

Transition probabilities are unknown. Agent learns by interacting with environment.

Q-Learning Update Rule

\[ Q_{t+1}(s,a) = Q_t(s,a) + \mathbf{1}_{[\{s_t, A_t\} = (s,a)]} \cdot \alpha_t \left[ r(s,a) + \lambda \max_{a' \in A} Q_t(s_{t+1}, a') - Q_t(s,a) \right] \]
αₜ = learning rate · λ = discount factor · The indicator 1[…] updates only when we visit state-action (s,a) · Q converges to optimal Q* under appropriate conditions.
Intuition Q(s,a) = expected total discounted reward of taking action a in state s, then acting optimally. · Optimal policy: π*(s) = argmax_a Q*(s,a).

10 ✈️ Revenue Management

Applied in airlines/hotels to decide how many seats to protect for high-paying customers. Uses the same newsvendor logic.

TermFormulaMeaning
Critical Ratio\(CR = 1 - \frac{r_L}{r_H}\)Same as newsvendor CR with C_u = r_H − r_L, C_o = r_L
Protection level y*\(y^* = a + CR \times (b-a)\)Seats reserved for high-fare class (business demand ~ U[a,b])
Booking limit b*\(b^* = \text{Total seats} - y^*\)Max economy seats that can be sold
Why CR = 1 − r_L/r_H? C_u = r_H − r_L (lost revenue by displacing a business passenger) · C_o = r_L (revenue blocked by holding a seat that goes empty) · Substituting into C_u/(C_u + C_o) = (r_H−r_L)/r_H = 1 − r_L/r_H ✅

12 📉 Exponential Smoothing & Trend Model

Simple Exponential Smoothing (ES)

\[ F_{t+1} = \alpha D_t + (1 - \alpha) F_t \]
F_t = forecast for period t · D_t = actual demand · α = smoothing constant (0 < α < 1)
Higher α → more responsive to recent changes · Lower α → smoother, less reactive
F₁ can be initialized as first data value, last data value, or simple average.

Trend Model (Linear Regression)

\[ F_t = a + b \cdot t + \varepsilon \]
Parameters a (intercept) and b (slope) fitted by least squares. Gives equal weight to all historical data.

Double Exponential Smoothing

ES applied to data with a linear trend causes a systematic lag:

\[ \text{Lag} = D_t - F_t = \frac{1-\alpha}{\alpha} \cdot b \]
Solution: apply ES twice (double smoothing) to estimate both level and trend, then project forward.

Final forecast formula: F₉ = a + b × (steps ahead), where a and b are derived from single and double smoothed values:

\[ b = (S_t - S_t'') \cdot \frac{\alpha}{1-\alpha}, \quad a = 2S_t - S_t'' \]
S_t = single smoothed value · S_t'' = double smoothed value

13 📊 Holt's Method & Winter's Model

Holt's Method (Trend + Level)

\[ F_{t+1} = a_t + b_t \] \[ a_t = \alpha D_t + (1-\alpha)(a_{t-1} + b_{t-1}) \quad \text{(level)} \] \[ b_t = \beta(a_t - a_{t-1}) + (1-\beta)b_{t-1} \quad \text{(trend/slope)} \]
Two smoothing constants: α for level, β for trend. Initialization: a₁ = D₁, b₁ = (D_N − D₁)/(N−1)

Winter's Model (Trend + Seasonality)

\[ F_{t+1} = (a_t + b_t) \times C_{t+1} \] \[ a_{t+1} = \alpha \frac{D_{t+1}}{C_{t+1}} + (1-\alpha)(a_t + b_t) \] \[ b_{t+1} = \beta(a_{t+1} - a_t) + (1-\beta)b_t \] \[ C_{t+p+1} = \gamma \frac{D_{t+1}}{a_{t+1}} + (1-\gamma)C_{t+1} \]
Three constants: α (level), β (trend), γ (seasonality) · C = seasonal index · p = season length
Multiplicative model: actual = level × trend × seasonal index
Model Selection Guide Only trend → Holt's · Only seasonality (no trend) → ES + seasonal index · Trend + seasonality → Winter's · Short-term correlation in residuals → AR/ARMA

14 🔢 AR, MA & ARMA Models

Box-Jenkins (1976) models — designed specifically for short-term forecasting. Work on de-meaned series: D̂ₜ = Dₜ − μ where μ = E[Dₜ].

AR(1) — Auto-Regressive order 1

\[ \hat{D}_t = \phi_1 \hat{D}_{t-1} + \varepsilon_t \]
φ₁ = auto-regressive coefficient · εₜ = error term · AR(p) generalizes to p past values

MA(1) — Moving Average order 1

\[ F_t = \mu - \theta \cdot \varepsilon_{t-1}, \quad \text{where } \varepsilon_{t-1} = D_{t-1} - F_{t-1} \]
θ = MA coefficient · This is NOT the same as simple moving average! It uses lagged forecast errors.

ARMA(1,1)

\[ \hat{D}_t = \phi_1 \hat{D}_{t-1} - \theta \cdot \varepsilon_{t-1} + \varepsilon_t \]
Combines AR(1) and MA(1). General form: ARMA(p, q) uses p past observations and q past errors.
⚠ Exam Trap The formula F_t = μ − θ·ε_{t-1} is the MA(1) model, NOT exponential smoothing. The exponential smoothing formula is F_{t+1} = αD_t + (1−α)F_t.

15 📡 IoT / IIoT — Fundamentals

Internet of Things (IoT): A network of interconnected devices — computers, gadgets, vehicles — all connected to the internet. Term dates from the late 1990s. Devices exchange and consume data with minimal human intervention. Once data reaches the cloud, software processes it and may trigger actions automatically.

Three Forms of IoT

FormTargetExamples
ConsumerIndividual usersSmart homes, TVs, refrigerators, wristwatches, geyser automation
CommercialBusiness servicesBanking, insurance, financial services, e-commerce
Industrial (IIoT)Manufacturing/IndustryFactories, supply chains, smart metering, predictive maintenance

IIoT vs IoT

IIoT (Industrial IoT) = IoT applied to industrial/manufacturing devices. Same underlying concept but different assets. Devices wirelessly connected to networks. Objective: increased efficiency and productivity through automation. Data sent to cloud for processing and decision-making.
