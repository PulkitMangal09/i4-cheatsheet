// problem 1 · step-by-step with all constraints explained

A company's demand over 4 months is: Month 1 = 1 unit, Month 2 = 3 units, Month 3 = 2 units, Month 4 = 4 units. Setup cost = $3 (if producing anything). Variable cost = $1/unit. Holding cost = $0.50/unit left at end of month. Max production = 5 units/month. Max ending inventory = 4 units. Starting inventory = 0. Find the minimum cost production schedule.
Step 01

Understand the cost structure

// three types of costs — know each one cold

Setup cost — $3 (fixed per month you produce)

Like switching the factory "on". Paid once if you produce any units, regardless of quantity. Produce 0 → pay $0. Produce even 1 → pay $3.

Variable cost — $1 per unit produced

Every unit costs $1 to make. Simple multiplication: produce x → pay $x.

Holding cost — $0.50 per unit remaining at month end

Units not sold sit in the warehouse and cost $0.50 each. This discourages over-producing early.

Step 02

The inventory equation

// one equation governs every month

Ending inventory = Starting inventory + Units produced − Demand
Rules: ending inv ≥ 0 (can't run out)  AND  ending inv ≤ 4 (warehouse limit)

Monthly cost formula

Cost(x) = Setup(x) + $1 × x + $0.50 × ending inventory
where Setup(x) = $3 if x > 0, else $0
Step 03

What is backward recursion DP?

// the core idea — solve from the end, work backwards

ft(I) — the value function

ft(I) = the minimum possible total cost from month t through month 4, given starting inventory I at month t. Our goal is f1(0).

ft(I) = min over all valid x of [ cost(x, I) + ft+1(I + x − demandt) ]
Base case: f5(I) = 0 for all I  (no costs after month 4)

Why valid x only?

Not every x from 0–5 is legal. Both constraints must be satisfied simultaneously:

Must meet demand: I + x − demand ≥ 0 → x ≥ demand − Ifloor
Warehouse limit: I + x − demand ≤ 4 → x ≤ 4 − I + demandceiling
Machine limit: x ≤ 5ceiling

Valid x = integers from max(0, demand − I) to min(5, 4 − I + demand)
